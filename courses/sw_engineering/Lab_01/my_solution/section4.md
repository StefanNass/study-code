# Functional Requirements

1. You can set alarm (user level)
2. Alarm goes on at time you set
3. You can put alarm off (user level)
4. You can snooze alarm
5. Alarm should turn on at snooze mode again (software level)
6. You can set different alarm sounds (system level)
7. You can set the volume of the speaker for alarm
8. You can choose between sound, vibration or both
9. You can set alarm once or for weekdays (software level)
10. Display should show the time (system level)
11. It should be able to change the time



# Non-Functional Requirements

1. In Snooze, alarm should go on 5 minutes later
2. If you don´t put alarm off, the alarm deactivates himself after 1 minute.
3. Alarm shoud turn on within 10 ms after reaching time
